# Website Gemeinde Großheide

Neue Website der Gemeinde Großheide (Ostfriesland). Statischer Export mit Next.js, barrierefrei nach BITV 2.0 / WCAG 2.1 AA.

```bash
npm install
npm run dev      # http://localhost:3000/de/
npm run build    # statischer Export nach out/
npm start        # out/ lokal ausliefern
```

Projektziele, Konventionen und alle Befehle: [CLAUDE.md](CLAUDE.md). Hosting: [docs/hosting.md](docs/hosting.md).
Fakten mit Quellen: [content/facts.json](content/facts.json).
